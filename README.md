#### Featured project · [Mercado en Luz](https://github.com/Marco-Garcia-G/proyecto-mercado-en-luz)

<a href="https://marco-garcia-g.github.io/proyecto-mercado-en-luz/"><img src="https://marco-garcia-g.github.io/proyecto-mercado-en-luz/figure/media/market-in-light.gif" width="520" alt="Mercado en Luz: a stock portfolio shown as green and red light on a 15-segment LED strip"></a>

A local web app that turns a stock portfolio into ambient light: each company owns a stretch of a Govee LED strip that glows green when it is up and red when it is down, driven over Bluetooth LE. Live quotes, interactive charts, a strip editor and native iOS and Android apps.
